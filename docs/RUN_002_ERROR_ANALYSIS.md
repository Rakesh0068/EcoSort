## Data limitations

- `misclassified_examples` stores a capped sample per confusion pair, not
  every error; pair counts come from the full matrix.
- No per-sample lighting/background/occlusion/quality/angle metadata exists
  in the eval artifact — those categories report "Not available".
- Test errors must never become training data (frozen set). They inform
  *which classes* to prioritize in active learning; the samples themselves
  stay out of v4.
